      Fetch function that returns every response as an IPropagation.

      An HTTP failure status is returned as a failed branch instead of being thrown. A route that declares an encrypted body and a transport failure still throw. The output must describe numeric status branches with boolean success and string or string-array headers; its data type remains caller-owned.
