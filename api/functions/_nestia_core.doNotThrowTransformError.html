    Function doNotThrowTransformError

    • doNotThrowTransformError(value?: boolean): void

      Chooses whether a decorator called without the compile-time transform throws.

      The initial configuration throws with instructions to build with ttsc. Calling this setter with false, including its omitted-argument default, silences the error. Passing true restores throwing for subsequent decorator construction. Decorators already constructed keep their selected callbacks.

      Parameters

      • value: boolean = false

      Returns void
